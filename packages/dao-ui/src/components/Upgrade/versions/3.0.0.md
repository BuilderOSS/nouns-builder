### Signed Proposals (proposeBySigs)

Governor V3 lets multiple token holders collectively sponsor a proposal instead of requiring one holder to meet the proposal threshold alone.

- Sponsors combine their voting power to meet the threshold
- A proposal can have up to 16 sponsors
- Any sponsor can cancel a signed proposal before execution

### New Proposal States

- **Updatable**: Proposal is in the updatable period
- **Replaced**: Proposal was updated and replaced by a new version

### Proposal Replacement Tracking

An update creates a new proposal version. The previous version is marked **Replaced**, while the original voting schedule and voting-power snapshot stay the same.

### Compatibility Note

Apps that create offchain vote signatures need to support the V3 format. Regular onchain voting is unaffected.
